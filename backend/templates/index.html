Leave & Attendance Management System

A role-based backend for managing employee attendance and leave requests.

API Endpoints

POST /api/token/ — obtain JWT (username/password)
POST /api/token/refresh/ — refresh JWT
POST /api/auth/register/ — register an employee
GET/PUT/PATCH /api/users/me/ — current user profile
POST /api/users/change_password/ — change password
GET /api/departments/ — list departments
GET/POST /api/attendance/ — attendance records
POST /api/attendance/check_in/ — check in
POST /api/attendance/check_out/ — check out
GET /api/attendance/summary/ — attendance summary
GET/POST /api/leaves/types/ — leave types
GET/POST /api/leaves/requests/ — leave requests
POST /api/leaves/requests/{id}/review/ — approve/reject
GET /api/leaves/balances/ — leave balances
